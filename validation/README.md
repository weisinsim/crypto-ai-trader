# Historical exit-parameter validation

## Purpose

Compare 2.5R and 3R take-profit distances while holding the entry signal and 2 ATR stop fixed. This is an audit harness, not proof of profitability and not an execution bot.

## Required input files

### candles.csv

UTF-8 CSV with columns:

```csv
timestamp,open,high,low,close
2026-01-01T01:00:00Z,100,102,99,101
```

- Timestamps must be ISO-8601 with timezone (or Unix epoch seconds/milliseconds).
- The timestamp must identify the candle close time and match the signal timestamp.
- Use one continuous market series, sorted automatically by timestamp.
- Exclude unfinished candles.

### signals.csv

UTF-8 CSV with columns:

```csv
timestamp,side,entry,atr
2026-01-01T01:00:00Z,LONG,101,1.2
```

- These signals must be generated by a frozen model using information available at or before the timestamp.
- Entry is the assumed signal-candle close. Execution slippage must be represented by costs or a separate fill model.
- ATR must be calculated causally, with no future bars.
- Do not generate these signals by tuning parameters on the final holdout.

## Run

```bash
python validation/exit_parameter_audit.py \
  --candles candles.csv \
  --signals signals.csv \
  --stop-atr 2.0 \
  --cost-bps 10 \
  --max-hold 72 \
  --holdout-fraction 0.30 \
  --out exit_audit_results.json
```

The cost is a round-trip cost in basis points of entry notional. It is a simplified cost assumption and should be stress-tested at several levels appropriate to the venue and order type. The 72-candle holding cap means 72 future candles at the input timeframe.

## Execution assumptions and limitations

- Exit checks start at the candle after the signal candle; this avoids using the signal candle's already-known high/low to claim a future fill.
- If stop and target are both touched within one OHLC candle, the stop is assumed first.
- Time exits use the last available close within the holding window.
- The script compares only the exit distance on fixed signals. It does not recalculate signals, simulate funding, model partial exits, account for overlapping positions, exchange liquidation, market impact, or portfolio exposure.
- Signals with no matching candle timestamp are skipped; check `matched_signal_rows` before interpreting output.
- The chronological split is a basic holdout only. For credible evidence, preserve a final untouched holdout and also run walk-forward folds without repeatedly selecting the winner on the holdout.

## Decision rule

Do not select 3R solely because its profit factor is larger in one sample. Compare net R, profit factor, drawdown, number of trades, performance by time fold, and sensitivity to higher costs. Require a meaningful sample and stability across multiple untouched periods. If the difference is small or unstable, retain 2.5R as the simpler baseline and label both as unvalidated until the signal model itself has been audited.

Never describe the results as live performance or deploy them to real funds based only on this script.
